# Clean-room studies

This directory contains source-free observations produced under
[`../CLEAN_ROOM.md`](../CLEAN_ROOM.md). It contains no copied code, prose,
prompts, tests, styles, assets, internal naming, or distinctive organization
from the ignored reference checkouts.

Each reference-informed work item gets an observation here, then a normalized
functional specification in [`../specs/`](../specs/README.md). Its implementer
receives that specification plus Airship's own canonical documents—not this
observation and never a checkout path. The first record,
[`2026-07-28-policy-adoption.md`](2026-07-28-policy-adoption.md), establishes the
baseline under which future studies proceed.
