Privacy disclosure · version 1.1.1

A small, inspectable boundary.

Airship Companion is an optional browser extension for the Airship edge agent. It does not operate an Airship backend and does not sell, profile, or advertise against user data.

Data handling

What crosses the extension

Provider relay
At a user-requested provider operation, bounded request and response bytes may pass through the background context to fixed, manifest-listed vendor hosts. Cookies are omitted, redirects are not followed, and traffic is not logged or stored by the extension.
Credentials
Provider credentials remain in the Airship page’s memory. They can transit a requested relay call but are never persisted by the extension.
Encrypted cache
Disabled by default. If the person enables it, extension-origin IndexedDB stores only caller-declared encrypted Airship pages under opaque identifiers. Records are bounded, integrity-checked, evicted under a fixed budget, and clearable from the popup.
Background compute
Bounded hashing and vector ranking use data supplied by the Airship page and return results to that same page. Inputs and results are not retained by the compute operation.
Telemetry
The extension contains no analytics, advertising SDK, remote code loader, or extension traffic logger.
Deletion
Clear the encrypted cache from the extension popup, disable the cache, or uninstall the extension. Removing browser extension data deletes its extension-origin store according to the browser’s own lifecycle.
Scope

Permissions are compiled in

Caller and destination allowlists are source-controlled. No page message can add a host, raise a byte ceiling, enable cache storage, or grant provider account authorization.
