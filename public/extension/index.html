What installation does—and does not—grant

Provider OAuth
The extension can transport only a supported, reviewed grant flow. It does not manufacture provider permission or embed a client secret.
Local storage
Disabled by default. When enabled from the popup, it accepts bounded encrypted Airship pages only; the Vault remains authoritative.
Compute
Moves bounded hashing and vector ranking off the interface thread. It uses the browser’s available execution context and makes no unmeasured GPU claim.
Trust
Installing the extension changes reachability, not provider authority. Airship still reports provider state separately, and the extension does not manufacture trust signals.
