# Archived documents

Everything under `docs/archive/` is historical.

These files describe earlier Airship designs, reviews, and experiments,
including the Chutes-centered period with provider-specific sign-in, E2EE
transport, attestation/evidence language, receipts, billing/account telemetry,
and older UI routes.

The active product contract is now the provider-neutral browser runtime
described in the living docs under `docs/`, especially
[`../SIMPLIFICATION.md`](../SIMPLIFICATION.md) and [`../CANON.md`](../CANON.md).

## How to read this directory

- Each archived Markdown file carries a deprecation banner at the top.
- Archived files are preserved for historical context, not active guidance.
- When an archived statement conflicts with a living document or the current
  tree, the living document and the code win.
- New edits should go to the living docs, not here.

## Contents

- Top-level files: retired specifications, plans, and reviews.
- `audit/`, `design-review/`, `gap-audit/`, `architecture/`: earlier working
  notes and migration inputs.
- `*.json` archives keep an explicit archive notice field instead of a Markdown
  banner.
